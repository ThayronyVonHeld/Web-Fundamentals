# 🌐 Lesson 1 — How Did the Internet Emerge?

The Internet emerged during the Cold War, around 1949, in a context of technological competition between nations.

The President of the United States, Dwight D. Eisenhower, created DARPA with the goal of developing advanced technologies for military purposes.

---

## 🖥️ The Creation of the First Network

To ensure that military data would not be lost during attacks, DARPA created the ARPANET, initially connecting four computers across military bases.

### ⚠️ Initial Problem:

The computers were from different manufacturers and had:

* Different languages
* Different architectures

👉 In other words: **they could not communicate directly.**

---

## 🔗 The First Solution: NCP

The NCP was created to allow computers to “speak the same language.”

### Limitation:

* Slow communication
* Only two computers could communicate at a time

---

## 🚀 Evolution: TCP/IP

As the network grew, new issues emerged related to performance and identification.

* Bob Kahn developed TCP
* Vint Cerf created IP

👉 Together, they formed **TCP/IP**, which is still used today.

### Functions:

* **TCP**: splits data into packets and reassembles them at the destination
* **IP**: identifies each device on the network

---

## 🌍 Network Expansion

ARPANET expanded and was divided into:

* **MILNET** → military use
* **NSFNET** → academic research
* Commercial networks

These networks needed to communicate with each other.

👉 This led to the concept of:

* **Interconnected Networking → Internetworking → Internet**

---

## 🌐 What is the Internet?

The Internet is **not a single network**, but:

👉 A **network of interconnected networks**, connected through global infrastructure such as submarine cables.

---

## 📡 How Does It Work in Practice?

Example: watching a video on YouTube

1. Your computer (client) sends a request
2. The server (e.g., Google) responds
3. The content is sent in **data packets (TCP/IP)**
4. Your computer reassembles the packets

---

## 🧾 Before the Modern Web

Before HTML and modern websites, there was Gopher:

* Text-based interface (terminal style)
* Simple navigation

---

## 🌐 The Birth of the Web (WWW)

In 1993, Tim Berners-Lee revolutionized the Internet by creating:

* **HTML** (page structure language)
* **HTTP** (communication protocol)
* **WWW** (World Wide Web)

👉 He also introduced the concept of **hyperlinks** (clickable links).

---

## 🌎 The First Web Browser

The first browser compatible with the Web was Mosaic, created by Marc Andreessen.

---

## ⚠️ Internet ≠ Web

* **Internet** → infrastructure (global network)
* **WWW** → a system that runs on the Internet

Other services also exist, such as:

* FTP (file transfer)
* Gopher

---

## 🧠 Final Summary

The Internet began as a military project designed to ensure secure communication. It evolved with protocols like TCP/IP into a global network of networks. With the creation of the Web by Tim Berners-Lee, it became accessible to the public and evolved into what we use today.
