## 🚀 Sobre o Projeto

Este repositório é um **roadmap estruturado e prático** para dominar o desenvolvimento web moderno do zero.

Ele é projetado não apenas como um repositório de estudos, mas como um **projeto de portfólio profissional**, combinando:

* 📚 Lições bem estruturadas
* 🧪 Exercícios práticos
* 🚀 Projetos do mundo real

---

## 🎯 Objetivos

* Construir uma **base sólida** em desenvolvimento web
* Criar um **portfólio pronto para oportunidades internacionais**
* Documentar a **jornada de aprendizado com clareza e consistência**

---
