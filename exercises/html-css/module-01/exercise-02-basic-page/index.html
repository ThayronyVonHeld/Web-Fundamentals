Aprendendo um pouco mais sobre as tags

Explicando a estrutura

<*!DOCTYPE html> → define HTML5

<*html lang="pt-br"> → idioma do site

<*head> → configurações

<*body> → conteúdo visível

Metadados importantes

<*meta charset="UTF-8"> → Permite acentos (ç, á, etc.)

<*meta name="viewport"> → Responsividade (adaptação a telas)

<*title> → Título da aba do navegador

Outras tags

<*h1> → Títulos do site

<*p> → Parágrafos do site

<*hr> → Adiciona uma linha horizontal

*Impotante

As tags não possuem (*), elas foram postas apenas para compatibilidade

Algumas tags não possuem fechamentos como <*hr>, outras obrigatoriamente possuem como <*p><*/p>
