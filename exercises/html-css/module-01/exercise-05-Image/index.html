Tags HTML!

Olá, você chegou no meu exercício 05!
Nesta aula, iremos aprender a como adicionar imagens e favicon em nosso site

Explicando a estrutura

<!DOCTYPE html> → Define HTML5

<html lang="pt-br"> → Idioma do site

<head> </head> → Configurações

<body> </body> → Conteúdo visível

Metadados importantes

<meta charset="UTF-8"> → Permite acentos (ç, á, etc.)

<meta name="viewport"> → Responsividade (adaptação a telas)

<title> → Título da aba do navegador

Outras tags

<h1> </h1> → Títulos do site

<p></p> → Parágrafos do site

<hr> → Adiciona uma linha horizontal

<br> → Quebra a linha em um lugar especifico

Observações

Para efeutar um comentário no codigo, basta digitar <!-- seu cometário -->

Algumas tags não possuem fechamento, como <hr>, enquanto outras obrigatoriamente possuem, como <p></p>.

Adicionando simbolos especiais

Por exemplo podemos adicionar o simbolo de marca registrada &+reg = ® ou copyright &+copy = ©, ™, €, £, ¥, ¢, Δ, ↑

Se quiser conhecer todos os simbolos acesse: Acessar documentação

Adicionando emoji

Para adicionarmos um emoji podemos acessar: Acessar emojipedia buscar o emoji que deseja adicionar → informações técnicas → Pontos de código → U+1F5A5

Desse código precisaremos somente do 1F5A5

Para adicionar o emoji basta digitar &*#x1F5A5; (sem o "*") e pronto 🖥

Adicionando imagens e favicon

<img src="url da imagem" alt="texto alternativo"> → para adicionar imagens

Adicionando com arquivos na mesma pasta: <img src="logo-html.png" alt="Logo HTML">

Adicionando com arquivos em outra pasta, precisamos especificar caminho, <img src= "assets/logo-css.png" alt="Logo CSS">

Adicionando com arquivos na web: <img src="https://upload.wikimedia.org/wikipedia/commons/d/d4/JavaScript-shield.svg" alt="Logo JavaScript">

Para ajustar tamanho da imagem podemos utilizar as css (futuras features)

Podemos também adicionar um favicon em nosso site (favicon é o icone na aba da guia do navegador) basta adicionar no <link rel="shortcut icon" href="seu caminho do favicon" type="image/x-icon">
